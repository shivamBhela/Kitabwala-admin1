Value / Implementation
Source DB
u101172427_newdev ΓÇö WordPress + WooCommerce + WCFM (Dokan unused)
Platform
Multi-vendor new books, stationery, school/college books, NCERT, competitive exam materials
Commission
10% platform fee. Vendor keeps 90%. Confirmed from live wp_wcfm_marketplace_orders data.
Delivery Zones
Local Rs.39 (free>Rs.500) | Bihar Rs.49 (free>Rs.599) | South Rs.59 (free>Rs.699) | Rest Rs.59 (free>Rs.799)
COD
Rs.7 flat per order. Admin sets per-pincode: full_cod / partial_cod / prepaid_only.
GST
Books 0%, Stationery 18%, Shipping 18%. Products carry base_price + gst_rate + hsn_code. Auto-invoice PDF per vendor.
Auth
Passwordless only. Phone OTP (Truecaller->WhatsApp->SMS fallback), Google OAuth, Email OTP. Legacy users keep
password_hash (not exposed in UI).
Payment
Razorpay (only active gateway confirmed). Cashfree also supported. Wallet top-up via both. No split payment.
Delivery
Same-day: own team, real-time GPS + OTP + photo proof. Normal: Shadowfax API auto-called.
Attempts
Normal max = 3. Same-day max = 1. On cancel: shipping deducted, rest refunded.
Returns
7 days from delivery. Wrong product only. Partial returns per item. Customer chooses original payment or wallet.
Coupons
KITABWALAH (10% no min), NEW10 (10% Rs.199 min), BIRTHDAY10 (10% birthday month max Rs.50), WELCOME30
(Rs.30 first order Rs.299 min). One coupon per checkout.
Cart
Persists in PostgreSQL. Same vendor+product = increment qty. Different vendors = separate rows.
Wallet
Real money. Razorpay/Cashfree top-up. Insufficient balance prompts top-up ΓÇö no split payment.
Reseller
Rs.25 wallet credit to referrer. First order of referred user only. Credited after delivery.
Homepage
Option C: auto-computed + admin pin override via homepage_pins table.
Search History
Last 5 searches per user stored in search_history table.
Source Tracking
wp_id on every migrated table. 19 tables have wp_id.
Guest Orders
680 historical guest orders NOT migrated. Guest checkout disabled on new platform.
Vendor KYC
Admin manually verifies. Simple form. kyc_form_data JSON for scalability.

Value / Implementation
Source DB
u101172427_UsedBooks ΓÇö custom-built app (NOT WordPress). 149 users, 157 books, 10 orders.
Platform
Used books marketplace. Every user is BOTH buyer AND seller. All users get vendor_profiles.
Commission
15% platform fee + Rs.8 platform charge per order. Vendor keeps 85% minus Rs.8.
Delivery
Rs.49 flat delivery charge (stored in app_settings). Same zone system as kitabwalah.
COD
Rs.7 flat per order. Same pincode-based COD rules as kitabwalah.
GST
Books 0% GST. products.gst_rate default 0. hsn_code optional.
Auth
Passwordless only. Same 3 methods: Phone OTP, Google OAuth, Email OTP.
Payment
Razorpay + Cashfree. Wallet top-up. No split payment.
Delivery System
SAME as kitabwalah: same-day (own team, GPS+OTP+photo) + normal (Shadowfax). Max attempts 3/1.
Condition
REQUIRED on every product ΓÇö no default. like_new / good / acceptable / poor. Migration: fair->acceptable, poor->poor.
Returns
SAME policy as kitabwalah: 7 days from delivery. Wrong product only. Partial returns per item.
Wallet
Real money wallet. Migrated wallet_balance from old UsedBooks.users. 14 wallet_transactions migrated.
Messages
REMOVED ΓÇö owner decision. Old UsedBooks.messages (8 rows) NOT migrated. No messaging on new platform.
Cart
Same rule: same vendor+product = increment qty. Different vendors = separate rows.
Source Tracking
ub_id on every migrated table. 13 tables have ub_id.
Separation
Completely separate PostgreSQL database. No cross-DB joins with kitabwalah. Ever.
Platform-Specific Features
Feature
Detail
Condition field
